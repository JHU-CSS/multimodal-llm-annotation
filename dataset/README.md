# TikTok dataset

2,157 TikTok videos across 18 hashtags, sampled with the TikTok Research API:
about 30 videos per hashtag per month for Oct 2025 to Jan 2026, US only, keeping
only videos with a speech transcript. Videos are not included.

## tiktok_data.csv

| Column            | Description                                  |
| ----------------- | -------------------------------------------- |
| `video_id`        | TikTok video ID                              |
| `sampled_hashtag` | Hashtag it was sampled under (one of the 18) |

Hashtags: anime, basketball, booktok, craft, dance, dogs, food, funnyvideos, gaming,
gym, homedecor, makeup, music, skincare, strangerthings, tech, travel, wealth.
